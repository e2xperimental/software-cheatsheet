## Finder

[10 Ways To Move Files From One Folder To Another In the Finder](https://youtu.be/3HWEok0xops?si=AD7wiAz4Pbfqbfr6)

### Same drive/volume

Dragging the file moves it by default.

### 1. Different drives/volumes (e.g., Mac to an external USB)

Dragging normally copies the file. To move it instead, hold down the Command (⌘) key while you drag and drop.

Source: [Apple Community](https://discussions.apple.com/thread/255360088?sortBy=rank)

### 2. Keyboard shortcuts (Cut and Paste equivalent)

1. Select the file and press Command (⌘) + C to copy it.
2. Navigate to and open the destination folder.
3. Press Option + Command (⌘) + V to move the file into the new location (removing it from the original spot)

Source: [Mac Basics: How To Move Files On a Mac](https://www.youtube.com/watch?v=ni0aNnmyENQ)

### 3. Right-Click (Context Menu)

1. Right-click (or Control-click) the file and select Copy.
2. Go to the destination folder and right-click in the empty space.
3. Press and hold the Option key on your keyboard.
4. The "Paste" option will change to Move Item Here—click it.

Source: [How to Cut / Move, Copy and Paste Files and Folders in Mac OS](https://youtu.be/-HdvdpVnuBY?si=NA7G1AX3fRHeFSmV)
